## 第一部分：規劃演算法複習

### 1) 問題定式
- **狀態**：x ∈ ℝ^n，**控制／動作**：u ∈ ℝ^m，**動態**：x_{t+1} = f(x_t, u_t) + w_t
- **成本／目標**：最小化 J = Φ(x_T) + ∑_{t=0}^{T-1} ℓ(x_t, u_t)
- **限制**：狀態限制（避障、關節角度限制）、控制限制（致動器範圍）、動態可行性
- **表徵**：構形空間 vs. 任務空間；占據格、帶號距離場（SDF）、機械臂運動鍊

### 2) 圖搜尋（離散規劃）
- **BFS**：無權圖找最少邊路徑
- **UCS／Dijkstra**：邊權非負時可得到最短成本
- **A***：使用 f(n) = g(n) + h(n)
  - 可容許啟發式：0 ≤ h(n) ≤ h*(n) ⇒ 最適性
  - 一致啟發式：h(n) ≤ c(n, n′) + h(n′) ⇒ 圖搜尋中無需重複展開節點
- 實務注意：運動基元離散化；平手處理；開／關集合；啟發式縮放；加權 A* 的速度－最適性折衷

### 3) 取樣式規劃（連續規劃）
- **PRM**：多次查詢；取樣無碰撞里程碑；以區域規劃器連接；漸近機率完備
- **RRT**：單次查詢；偏向未探索空間；朝取樣點延伸
- **RRT***：重接線帶來漸近最適；需要合適的轉向／區域規劃器與半徑策略
- 實務注意：碰撞檢查主導時間；最近鄰資料結構；尊重動態的轉向；目標偏置；知情取樣（如橢球域）

### 4) 軌跡最佳化
- **CHOMP／TrajOpt**：以碰撞成本與平滑項優化軌跡參數化
- **iLQR／DDP**：對名目軌跡做二階法；動態線性化、成本二次化；反向傳播得局部控制律
- 優點：平滑且動態可行；可明確處理梯度與限制
- 限制：局部極小；對初始解敏感；需要可微分模型或近似

### 5) 模型預測控制（MPC）與 MPPI
- **MPC**：反覆解有限視野最佳化，套用首個控制，視野前移
- **MPPI（路徑積分控制）**：以取樣為基礎的隨機最適控制
  - 對 K 組含雜訊的控制序列 U + ε 展開；計算各軌跡成本 J_i
  - 權重 w_i ∝ exp(−J_i / λ)，λ 為溫度參數
  - 用加權雜訊平均更新控制：u_t ← u_t + ∑_i w_i ε_{i,t}
  - 優點：免梯度、可平行；可處理非凸成本地形
  - 調參：溫度 λ、雜訊共變 Σ_ε、視野 H、樣本數 K、控制界限、成本塑形

### 6) 限制、碰撞與安全
- 限制層級：硬限制（不可行狀態）、軟限制處罰、障壁／增廣拉格朗日
- 碰撞檢查：精確幾何 vs. 近似（球／盒）、SDF 查詢；連續 vs. 離散檢查
- 安全邊界：以機器人半徑膨脹障礙；以不確定性緩衝做魯棒化

### 7) 不確定性與信念空間規劃（概覽）
- 程序與觀測雜訊；對狀態的信念 b_t
- 不確定性下規劃：POMDP、信念空間規劃、風險度量（CVaR、機率限制）
- 實務：魯棒成本、對變異懲罰、以移動視野頻繁再規劃

### 8) 複雜度與折衷
- 圖搜尋：對分支因子與深度呈指數；A* 受啟發式引導
- 取樣式：樣本數主導；最近鄰搜尋可用空間樹 O(log N)
- 軌跡最佳化：每次迭代為線性／二次解；以熱啟動取得即時性
- MPPI：O(K·H) 展開；擅長 GPU／平行擴展

### 9) 速查公式與定義
- A* f(n) = g(n) + h(n)；可容許 ⇒ 最適；一致 ⇒ 無重展開
- RRT* 重接線半徑 r_n = γ( log n / n )^(1/d)，d 為維度（理論形式）
- MPPI 權重：w_i = exp(−J_i / λ) / ∑_j exp(−J_j / λ)；以加權雜訊更新控制
- iLQR：線性化 x_{t+1} ≈ A_t x_t + B_t u_t + c_t；反向傳遞得 K_t, k_t；前向展開更新軌跡

### B. 程式（寫作或閱讀）
1) 實作加權格點的 A*，回傳路徑或失敗。提供主要迴圈與資料結構。

```python
import heapq

def astar(start, goal, neighbors_fn, cost_fn, heuristic_fn):
    open_heap = []  # (f, g, node, parent)
    heapq.heappush(open_heap, (heuristic_fn(start, goal), 0.0, start, None))
    came_from = {}
    best_g = {start: 0.0}

    while open_heap:
        f, g, node, parent = heapq.heappop(open_heap)
        if node in came_from:
            continue  # 已用更佳 g 展開
        came_from[node] = parent
        if node == goal:
            path = [node]
            while came_from[path[-1]] is not None:
                path.append(came_from[path[-1]])
            path.reverse()
            return path

        for nbr in neighbors_fn(node):
            step = cost_fn(node, nbr)
            tentative_g = g + step
            if tentative_g < best_g.get(nbr, float('inf')):
                best_g[nbr] = tentative_g
                h = heuristic_fn(nbr, goal)
                heapq.heappush(open_heap, (tentative_g + h, tentative_g, nbr, node))

    return None
```

2) 對半徑 r 的圓形機器人與軸對齊矩形障礙物進行碰撞檢查。

```python
def circle_collides_rect(cx, cy, r, rect):
    # rect = (xmin, ymin, xmax, ymax)
    xmin, ymin, xmax, ymax = rect
    closest_x = min(max(cx, xmin), xmax)
    closest_y = min(max(cy, ymin), ymax)
    dx = cx - closest_x
    dy = cy - closest_y
    return (dx*dx + dy*dy) <= r*r
```

3) RRT 延伸步驟：由最近節點 q_near 朝 q_rand 以步長 η 延伸。

```python
import math

def steer(q_near, q_rand, eta):
    dx = q_rand[0] - q_near[0]
    dy = q_rand[1] - q_near[1]
    dist = math.hypot(dx, dy)
    if dist <= eta:
        return q_rand
    scale = eta / (dist + 1e-12)
    return (q_near[0] + scale*dx, q_near[1] + scale*dy)
```

4) MPPI 權重更新與單一步控制修正（擬 Python）：

```python
import numpy as np

def mppi_update(u_t, noises_t, costs, temperature_lambda):
    weights_unnorm = np.exp(-(costs - costs.min()) / max(1e-8, temperature_lambda))
    weights = weights_unnorm / (weights_unnorm.sum() + 1e-12)
    delta_u = (weights[:, None] * noises_t).sum(axis=0)
    return u_t + delta_u
```

5) 已知 SDF 函數 d(x)（>0 為自由、<0 為碰撞），為點機器人建立在邊界 μ 內之二次懲罰成本。

```python
def sdf_collision_cost(x, sdf_fn, margin, weight):
    d = sdf_fn(x)
    if d >= margin:
        return 0.0
    return weight * (margin - d) ** 2
```
